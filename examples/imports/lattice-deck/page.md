## What it is

Lattice Deck is a programmable presentation and live graphics workbench. Its sample deck combines charts, procedural geometry and animated scenes. Edit a slide, change its parameters, and run the presentation in the same application.

The hosted version supports model-assisted editing and collaboration rooms. Model requests use the site's shared hosting limits; the graphics and presentation controls run in your browser.

## Why we made it

A presentation can contain executable graphics as well as text and images. This experiment puts both in an editable document, so the code producing a scene remains available while presenting it.
