    Display

    Every console element here still does its job: A confirms, B backs out, the health bar drains and the inventory holds your things. Each screen's UI is drawn plainly, the way Lattice draws its widgets. The shaders receive only that picture and the game state, then take it apart. Each screen renders at 256×192, as it would on the device, and is scaled up without smoothing. None of this has run on the RG DS Plus yet.
